# ATM-Management-System

A menu-driven ATM simulation in **Python 3**. Log in with a PIN, then check balance, deposit, withdraw, or view a mini statement. Data is saved in `atm.txt`.

**Student:** [Sameer Kumar Bhaskar] | **Enrollment No.:** [01091]
**University:** Rungta International Skills University (B.Tech CSE with IBM, Semester 1)

## Features
- PIN login with 3 attempts
- Check balance, deposit, withdraw
- Mini statement (last 5 transactions)
- Handles invalid input and file errors
- Saves data after every operation

## Concepts Used
Conditions, Loops, Functions, Exceptions, File Handling
